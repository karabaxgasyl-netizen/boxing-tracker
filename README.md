# 🥊 Бокс-трекер

Приложение для телефона: бег с GPS (счётчик метров), круги в зале, таймер раундов, привычки и итоги.
Работает без интернета, данные хранятся на телефоне.

## Как выложить в интернет (GitHub Pages, бесплатно)

1. Зайди на github.com → **New repository** → имя, например, `boxing-tracker` → **Public** → **Create repository**.
2. Нажми **uploading an existing file** и перетащи все файлы из этой папки (вместе с папками `icons` и `fonts`) → **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → **Save**.
4. Через 1–2 минуты сайт откроется по адресу `https://ТВОЙ-ЛОГИН.github.io/boxing-tracker/`.

GPS работает только по https — GitHub Pages даёт его сам.

## Как поставить на телефон

- **iPhone (Safari):** открой ссылку → «Поделиться» ⬆️ → «На экран „Домой“».
- **Android (Chrome):** открой ссылку → ⋮ → «Добавить на главный экран» (или кнопка «Установить» в приложении).
- При первом старте пробежки разреши доступ к геопозиции.

## Советы

- Во время бега не блокируй телефон и не сворачивай приложение — браузер может перестать отдавать GPS. Экран сам не гаснет, пока идёт пробежка.
- В зале GPS не работает — выбирай режим «Зал · круги» и задай длину круга (1 шаг ≈ 0,7 м).
- Раз в пару недель жми ⚙️ → «Сохранить копию», чтобы не потерять данные.
- На iPhone вибрации в браузере нет, а звук не слышно в беззвучном режиме — голосовые подсказки работают.

## Обновление

Поменял файлы → увеличь версию в `sw.js` (например, `boxtrack-v2` → `boxtrack-v3`), чтобы телефон подхватил новую версию.
